## แบบฝึกหัด: ./mvnw dependency:tree

| library / starter | มีไว้ทำอะไร |
|---|---|
| spring-boot-starter-test | ชุด starter หลักของ Spring Boot ที่รวบรวม library สำหรับเขียนและรัน test ทั้งหมดมาให้ในตัวเดียว |
| junit-jupiter | ใช้สำหรับเขียนโครงสร้างและรัน unit test ด้วย annotation เช่น @Test |
| assertj-core | ใช้เขียนคำสั่งตรวจสอบค่าผลลัพธ์ (assertion) ให้อ่านเข้าใจง่าย เช่น assertThat(x).isEqualTo(y) |
| mockito-core | ใช้สร้างวัตถุจำลอง (mock / test double) เพื่อแยกส่วนที่ต้องการทดสอบออกจากส่วนอื่น |
| hamcrest | ใช้สร้างเงื่อนไขการเปรียบเทียบและจับคู่ค่า (matcher) ในการตรวจสอบผลลัพธ์ของ test |

## Reflection (2–3 ประโยคต่อข้อ)

1. red bar แรกพิสูจน์อะไร ที่ green bar อย่างเดียวพิสูจน์ไม่ได้
พิสูจน์ว่าชุดทดสอบ (Test) ที่เราเขียนขึ้นมานั้นทำงานได้จริงและสามารถตรวจจับข้อผิดพลาดได้เมื่อโค้ดยังไม่ถูกต้อง เพราะหากเห็นเพียงผลลัพธ์ที่ผ่าน (green bar) อย่างเดียว อาจเกิดจาก Test ที่เขียนผิดพลาดจนปล่อยผ่านทุกกรณีโดยไม่ได้ตรวจสอบเงื่อนไขจริง

2. ถ้าเครื่องของคุณหายวันนี้ จะกู้งานกลับมาได้จากที่ไหน
   สามารถกู้คืนงานทั้งหมดกลับมาได้จาก Repository บนเว็บไซต์ GitHub โดยทำการ clone โปรเจกต์ลงในเครื่องใหม่ แต่จะกู้คืนได้เฉพาะโค้ดส่วนที่เราได้บันทึกประวัติ (git commit) และส่งขึ้นไปเก็บไว้บนเซิร์ฟเวอร์ (git push) เรียบร้อยแล้วก่อนที่เครื่องจะหายเท่านั้น
